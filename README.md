|---|---|---|---|---|

---

## Course Objective

To make the students understand the basics of NoSQL and MongoDB concepts.

---

## List of Programs

| # | Program |
|---|---------|
| 1 | Install, configure, and manage the MongoDB server across different operating systems |
| 2 | Create, switch, list, and delete databases in MongoDB |
| 3 | Create, view, and remove collections dynamically |
| 4 | Perform CRUD operations including insert, query, update, and delete documents |
| 5 | Use basic aggregation pipeline stages like `$match`, `$group`, `$project`, `$sort`, and `$limit` |
| 6 | Apply advanced aggregation techniques such as averages, joins, and array unwinding |
| 7 | Implement indexing and analyze query performance for optimization |
| 8 | Work with geospatial data and perform location-based queries |
| 9 | Manage database security, user roles, and backup/restore operations |
| 10 | Integrate MongoDB with Python using `pymongo` for data operations and analysis |
| 11 | Use MongoDB for real-world data analysis and trend identification |

| CO | Description |
